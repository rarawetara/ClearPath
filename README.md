# ClearPath 🧠✨

ИИ-коуч для фокусировки, планирования и мотивации.

## Стек
- React, TypeScript
- Zustand, Tailwind
- Vite
- OpenAI API (в процессе интеграции)

## Возможности (MVP)
- 🎯 Цели с прогрессом
- ✅ Задачи, связанные с целями
- 📅 Календарь задач
- 💬 Чат с коучем (мок + GPT)
- 📊 Обзор активности
